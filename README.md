# Dandihub

> [!IMPORTANT]
> **DANDI Hub has been retired.**
> The service was shut down in August 2026 and all user data has been deleted.
>
> To run notebooks against DANDI data, see
> **[notebooks.dandiarchive.org](https://notebooks.dandiarchive.org)**.
>
> For background and history, see the
> [DANDI Hub documentation](https://docs.dandiarchive.org/user-guide-using/dandi-hub/).
>
> This repository is kept for historical reference and is no longer maintained.

This was the user-facing repository for our deployment of Jupyterhub.
Configuration was handled in a [private repository](https://github.com/dandi/nebari-deployments/).

## Documentation

Please see our [DANDI Hub user documentation](https://docs.dandiarchive.org/user-guide-using/dandi-hub/) for more information.
